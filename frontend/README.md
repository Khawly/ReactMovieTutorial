This is a tutorial for React where you can search for movies and favorite them to add them to your favorites page.

I also went past the tutorial and added: the description, genres, rating for each movie, a fixed size to the movie cards in the favorites page, prevented favorited movies from disappearing when refreshing the page, and a "no image found" image for movies without an image.

Enter "npm run dev" in the "front end" directory to run the application on your localhost.
